2. 테스트 만들기(하네스의 두 번째 장치인 센서)
```
CLAUDE.md와 input_data/api_test_cases.json을 읽고 tests/ 폴더에 pytest 테스트를 작성해줘.
- api_test_cases.json의 12개 케이스를 그대로 테스트로 옮긴다
- 미래 날짜를 거부하는 케이스를 TC13으로 하나 추가한다 (input_data는 수정하지 않는다)
- conftest.py에서 dependency_overrides와 tmp_path로 임시 DB를 쓴다
- 앱 코드(app/)는 만들지 마
```

3. 일을 맡기기 전에 채점 기준을 실제로 고칠 수 없게 잠그기
```
프로젝트 루트에 .claude/settings.json 파일을 만들고 아래 내용을 그대로 넣어줘.
다른 설정은 추가하지 마.

{
  "permissions": {
    "deny": [
      "Edit(./tests/**)",
      "Write(./tests/**)",
      "Edit(./input_data/**)",
      "Write(./input_data/**)"
    ]
  }
}
```
4. 앱 만들기다. 
- 지금까지 만든 가이드(CLAUDE.md), 센서(tests), 잠금(settings.json) 안에서 AI에게 처음으로 실제 일을 맡김.
```
CLAUDE.md를 따라 app/ 폴더에 JobTracker 앱을 구현해줘.
uv run pytest가 전부 통과할 때까지 실행하고 고쳐.
테스트가 실패하면 앱 코드를 고친다.
```
[] 끝난 뒤 확인할 것 (완료 기준)
